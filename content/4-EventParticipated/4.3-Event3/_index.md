# FCAJ x Agentic AI Build Week: Show Up. Build. Pitch. WIN!

> **Event Video:** [Watch on YouTube](https://www.youtube.com/watch?v=hz32VBrvW7M)

![FCAJ x Agentic AI Build Week](/images/event3.jpeg)

### Event Objectives

- Drive developer and student participation in building practical Agentic AI applications on AWS Cloud infrastructure.
- Shift mindset from conversational Generative AI (chatbots) to Autonomous Agentic Workflows capable of executing complex real-world tasks.
- Foster a hands-on competition environment ("Show Up. Build. Pitch. WIN!") to enhance teamwork, rapid prototyping, and live technical presentation skills before AWS experts.

### Speakers & Organizers List

- **FCAJ & AWS Study Group Experts** – Solution Architects, Technical Leads & AI Engineers from First Cloud AI Journey (FCAJ) and AWS Community Vietnam.

---

### Key Highlights & Sessions

#### 1. Mindset Shift: From Chatbots to Agentic AI Systems
- **The AI Paradigm Shift:** Generative AI is rapidly evolving from basic text prompts to autonomous AI Agents that can plan multi-step workflows, execute tools, query databases, and self-correct runtime errors.
- **The "Show Up. Build. Pitch. WIN!" Philosophy:** Emphasizing action-oriented execution — rapidly transforming innovative concepts into functional AI prototypes within a structured build week.

#### 2. Cloud Architecture & Agentic AI Tooling on AWS
- **Foundation Models & Frameworks:** Leveraging **Amazon Bedrock** for foundation model hosting alongside agent frameworks (Custom Agents, Kiro Agent, LangChain/LangGraph).
- **Function Calling & Tool Integration:** Enabling agents to interface with external REST APIs, AWS Lambda serverless handlers, and databases (DynamoDB / PostgreSQL) to execute end-to-end tasks automatically.
- **GenAIOps & Observability:** Monitoring agent reasoning traces, latency, token budgets, and response accuracy in cloud environments.

#### 3. Hands-on Build & Prototype Engineering
- **Multi-Agent Orchestration:** Designing systems where specialized agents collaborate (e.g., Data Extraction Agent, Code Execution Agent, Quality Verification Agent).
- **Cloud-Native Integration:** Connecting AI agents with AWS serverless services (AWS Lambda, EventBridge, S3, DynamoDB) to create scalable backend architectures.

#### 4. Live Pitching & Technical Evaluation
- **Live Demo Presentations:** Presenting working Agentic AI applications live on stream.
- **Expert Architectural Review:** Receiving direct feedback from AWS Solution Architects regarding scalability, security posture, cost optimization, and user experience.

---

### Key Takeaways

1. **The Rise of Agentic AI:**
   - Autonomous AI Agents represent the next frontier in cloud computing. Learning to build and orchestrate multi-agent workflows is becoming an essential skill for modern cloud engineers.

2. **Cloud Infrastructure as the Foundation for AI:**
   - AI Agents require robust cloud backends (AWS Lambda, EventBridge, DynamoDB, Bedrock) to execute tasks reliably, securely, and at global scale.

3. **Rapid Prototyping & Action-Oriented Mindset:**
   - In fast-moving AI domains, rapid execution and hands-on building ("Build & Pitch") yield far deeper insights than theoretical design alone.

4. **Human-AI Synergy in Software Development:**
   - Developers are evolving into conductors of agentic workflows — setting objectives and constraints while leveraging agents to automate repetitive execution.
